# Arabic wording for review

Every visible string in the app, generated from `src/i18n/strings.ts` (the single strings file).
The Arabic is a draft: change it here or tell me the changes, and I will update the strings file.
`{count}`, `{time}` and similar are filled in by the app; keep them as they are.

Decided wording (Phase 2b): "New entry" = مادة جديدة, "My drafts" = مسوداتي, the Notes button = ملاحظات,
launcher name "My Notes" in both languages. Digits are Western (0-9) everywhere.
